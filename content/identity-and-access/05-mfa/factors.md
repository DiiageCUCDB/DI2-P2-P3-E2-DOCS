The policy applies to the factors **actually verified**.

| Category | Definition |
|---|---|
| **Knowledge** | Something the user knows: password, PIN. |
| **Possession** | Something the user has: a device holding a private key or a TOTP secret. |
| **Inherence** | Something the user is: a biometric used locally by an authenticator. |

> [!important] Application to the project
> For an administrator account, evaluate the MFA policy **on every flow** before issuing the authorization code.
