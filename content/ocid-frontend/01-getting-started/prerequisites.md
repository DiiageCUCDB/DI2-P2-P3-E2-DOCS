| Tool | Version / note |
| ---- | -------------- |
| Node.js | `^22.18.0` or `>=24.12.0` (see `engines` in `package.json`) |
| npm | Bundled with Node |
| Git | Any recent version |
| Docker | Optional, see [[05-devops/docker\|Docker]] |

## Editor

Recommended: **VS Code** with the extensions listed in `.vscode/extensions.json`:

- `Vue.volar` (Vue Official, disable Vetur)
- `dbaeumer.vscode-eslint`
- `EditorConfig.EditorConfig`
- `oxc.oxc-vscode`
- `esbenp.prettier-vscode`

## Browser

Chromium-based browsers or Firefox, with the Vue.js devtools extension. In Chrome/Firefox DevTools, enable *Custom Object Formatter*.
