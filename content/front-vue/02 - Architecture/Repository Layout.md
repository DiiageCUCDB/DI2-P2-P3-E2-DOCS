# Repository Layout

```
.
├── .github/workflows/        test.yml, sonar.yml, docker.yml
├── .vscode/                  extensions.json (recommended extensions)
├── cypress/
│   ├── e2e/                  *.feature scenarios + classic *.cy.ts specs
│   ├── fixtures/             test data
│   └── support/
│       ├── step_definitions/ Gherkin steps (common.steps.ts, ...)
│       ├── commands.ts       custom Cypress commands
│       ├── component.ts      component-test setup (registers cy.mount)
│       ├── component-index.html
│       └── e2e.ts            e2e setup
├── public/                   static files copied as-is (favicon.ico)
├── src/                      application code (see Source Folders note)
├── CHANGELOG.md              generated by semantic-release
├── Dockerfile                multi-stage: node build, nginx runtime
├── compose.yml               production image on port 8080
├── compose.dev.yml           dev server container (profile dev)
├── cypress.config.ts         e2e + component + Cucumber config
├── eslint.config.ts          ESLint flat config
├── index.html                Vite entry HTML
├── nginx.conf                SPA fallback + asset caching
├── sonar-project.properties  SonarCloud project
├── tsconfig*.json            see [[TypeScript and Path Alias]]
└── vite.config.ts            plugins + `@` alias
```
