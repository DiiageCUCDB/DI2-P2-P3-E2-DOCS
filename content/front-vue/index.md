# OCID

Front-end web application of the **DI2-P2P3-E2-OCID** project, built with Vue 3, TypeScript and Vite.

## Quick start

```sh
git clone https://github.com/DiiageCUCDB/DI2-P2P3-E2-OCID.git
cd DI2-P2P3-E2-OCID
npm install
npm run dev        # http://localhost:5173
```

Requires Node.js `^22.18.0` or `>=24.12.0`.

## Common commands

| Command | Purpose |
| ------- | ------- |
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Type-check and production build |
| `npm run lint` | oxlint + ESLint |
| `npm run test:unit` | Cypress component tests |
| `npm run test:e2e` | Gherkin e2e tests |
